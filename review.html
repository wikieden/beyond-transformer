B01 · 一次猜测的交叉熵 loss 怎么算？为什么前面有负号？为什么不用 1 − p？

来源：第 1 章 · 加入 2026-11-14 · 复习记录：（必背公式，还没考）

答案
\[\ell = -\log p_\theta(x_{i+1} \mid x_{1:i})\]

p 是模型给正确答案那个词的概率（只看这一格）。log p 在 0 < p < 1 时是负数，加负号翻成正的扣分：p = 1 → 0；p = 0.9 → 0.105；p = 0.537 → 0.622；p = 0.05 → 2.996；p = 0.01 → 4.605。

1 − p 最多扣 1 分，分不清 0.01 和 0.001（0.99 vs 0.999）；−log p 没有上限，越自信地猜错罚得越重。另外 \(\log(ab) = \log a + \log b\)：整句概率连乘，取 log 后变成每个词的 loss 相加。

又叫 NLL（Negative Log-Likelihood：负 / 对数 / 似然）。叫交叉熵是因为 \(-\sum_a q_a \log p_a\) 里 q 只有正确词是 1（Dirac delta），只剩 \(-\log p_{\text{正确词}}\)（handout 脚注 7）。

B02 · 从 logits 直接算交叉熵，公式是什么？为什么先减最大值？

来源：第 1 章 · 加入 2026-11-14 · 复习记录：（必背公式，还没考）

答案
\[\ell_i = -\log \text{softmax}(o_i)[x_{i+1}] = -\,o_i[x_{i+1}] + \log \sum_a e^{o_i[a]}\]

用 \(\log(a/b) = \log a - \log b\) 和 \(\log e^{x} = x\)，log 和 exp 抵消，不用先算出很小的概率（handout L1392–L1396）。例：前作第 22 章 8 个分数，bites = 2.9，\(\sum e^{o} \approx 33.86\)，log ≈ 3.522，ℓ = −2.9 + 3.522 = 0.622。

减最大值：\(\log \sum_a e^{o_a} = \max(o) + \log \sum_a e^{o_a - \max(o)}\)。所有分数减同一个数，softmax 不变；最大项变成 \(e^0 = 1\)，不会溢出（\(e^{1000}\) = inf）。整个训练集的 loss 是所有句子、所有位置取平均（式 16），一次前向就拿到所有位置（causal mask）。

B03 · 困惑度 perplexity 怎么算？怎么理解？刚开始训练时应该是多少？

来源：第 1 章 · 加入 2026-11-14 · 复习记录：（必背公式，还没考）

答案
\[\text{perplexity} = \exp\left(\frac{1}{m} \sum_{i=1}^{m} \ell_i\right)\]

先对 loss 取平均，再取 e 的次方（handout 式 18）。读作"模型平均相当于在几个词里犹豫"：k 个词里平均瞎猜，loss = log k，困惑度 = k。全对 = 1；词表 10000 的模型刚开始 loss ≈ log 10000 ≈ 9.21，困惑度 ≈ 10000。AIAYN base 的 4.92 是按 BPE token 算的，不能和按整词算的比（Table 3 注）。

B20 · 链式法则是什么？反向传播怎么一次算出所有参数的梯度？

来源：第 2 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 导数是斜率；梯度是所有偏导数排成的向量，指向 loss 涨得最快的方向；SGD：θ ← θ − α∇L。
  • 链式法则：函数套函数，导数连乘，dy/dx = dy/du · du/dx（例：(3x + 1)² 在 x = 1 是 8 × 3 = 24）。
  • 反向传播：前向存下每层的中间结果；反向从 loss 出发，“下游梯度 × 本层局部斜率”一层层乘回去。线性层 y = Wx：∂L/∂W = (∂L/∂y)xᵀ，∂L/∂x = Wᵀ(∂L/∂y)；ReLU 乘开关 [a > 0]，被关掉的单元梯度为 0。
  • 每个中间量的梯度只算一次、被上游共用，所以计算量和前向同量级（约 2 倍），代价是要存中间结果。

口诀：前向存中间，反向乘回去：下游梯度乘本层斜率

B21 · softmax + 交叉熵对 logits 的梯度是什么？怎么检查自己的梯度对不对？

来源：第 2 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • ∂L/∂o = p − y（y 是 one-hot）：错误类往下压、正确类往上抬，分量和为 0；正确类概率越接近 1，梯度越小。
  • 推导：L = −o_y + log Σe^{o_a}，对 o_k 求导得 −[k = y] + p_k。
  • 梯度检查：每个参数挪 ±ε，用 (L(θ + ε) − L(θ − ε))/2ε 和反向结果比相对误差（例：4.6e-11）；每个参数两次前向，只能查小例子；真训练用自动求导。

口诀：softmax 接交叉熵，梯度就是 p 减 y

B22 · SGD 在窄长山谷里为什么慢？Momentum、Adam 各改了什么？偏差修正修的是什么？

来源：第 3 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • f = ½(10x² + y²)：SGD 沿 x 每步乘 1 − 10α，要 α < 0.2 才不发散；最陡的方向卡住学习率，缓的方向走得慢。
  • Momentum：v ← βv + g，θ ← θ − αv；同向的梯度累积（约 1/(1 − β) 倍）、来回的抵消。
  • Adam：m ← β₁m + (1 − β₁)g，v ← β₂v + (1 − β₂)g²，θ ← θ − α m̂/(√v̂ + ε)：每个参数按自己的梯度大小归一化步长，对梯度尺度不敏感。
  • 偏差修正：m、v 从 0 开始，前几步偏小；m̂ = m/(1 − β₁ᵗ)、v̂ = v/(1 − β₂ᵗ)。第 1 步修正后每个参数都走 α（例：g = 4 → m̂ = 4、v̂ = 16）。t 从 1 数。

口诀：Adam 每参数一把尺，开头被零拖小，修正除以一减 β 的 t 次方

B23 · AdamW 和 Adam + L2 有什么区别？用 AdamW 每个参数要存几份？

来源：第 3 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • Adam + L2：λθ 加进梯度，再被 √v̂ 除掉，衰减强度和梯度大小、和 λ 纠缠在一起（例：梯度为 0 时每步都减 α，λ = 0.1 和 0.01 结果一样）。
  • AdamW：衰减单独做 θ ← θ − αλθ（解耦），λ 多大就衰减多少。a1 把偏差修正并进学习率 α_t = α√(1 − β₂ᵗ)/(1 − β₁ᵗ)。大模型常用 β = (0.9, 0.95)。
  • fp32 训练每个参数：参数 4 B + 梯度 4 B + m 4 B + v 4 B = 16 B（1 亿参数 1.6 GB），还不算激活。

口诀：衰减别混进梯度，AdamW 单独减 αλθ；参数梯度加两矩，十六字节

B24 · warmup + cosine 调度的公式是什么？为什么要 warmup？

来源：第 4 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • t < Tw：α_t = (t/Tw)αmax；Tw ≤ t ≤ Tc：α_t = αmin + ½(1 + cos((t − Tw)/(Tc − Tw)·π))(αmax − αmin)；t > Tc：αmin。退火走一半时在两端中点。
  • 原版 Transformer：d^{-0.5}·min(step^{-0.5}, step·warmup^{-1.5})；现在也常用 WSD（预热、平稳、最后快速衰减）。
  • warmup 的理由：开头参数随机、梯度乱；Adam 的 v̂ 只看了几步，可能偶然很小，一除步长特别大（例：第 1 步 √v̂ 的 90% 范围 [0.06, 1.92]，500 步后 [0.95, 1.06]）；Post-LN 开头梯度大。

口诀：线性升到峰，余弦降到底，之后停在最低；开头 v̂ 不准，warmup 走小步

B25 · 梯度裁剪怎么做？为什么按全局范数整体裁？

来源：第 4 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 所有参数的梯度拼成一个向量，算 ℓ2 范数 ‖g‖；超过 M 就整体乘 M/(‖g‖ + ε)（ε = 10⁻⁶），否则不动。例：[3, 4]、M = 1 → [0.6, 0.8]。
  • 整体缩放只改长度、不改方向；每个参数单独裁会改变方向。
  • 裁剪前的范数要记进日志：偶尔尖峰被裁没关系，几乎每步都在裁说明学习率太大或训练不稳。常取 M = 1.0。

口诀：所有梯度拼一条，超长就按比例缩，方向不变

B26 · batch 是怎么从语料里切出来的？总 token 数怎么算？

来源：第 5 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 所有文档拼成一长串，中间插 <|endoftext|>；随机挑 B 个起点，x = s[i : i+m]，y = s[i+1 : i+m+1]（错开一位），形状都是 (B, m)。长 n 的串有 n − m 个可选起点。
  • 好处：不用补齐、不用把数据全读进内存（memmap）；代价是片段可能跨文档。
  • 总 token 数 = B × m × 步数（a1 TinyStories 要求 327,680,000），是比较不同配置的公共尺子；训练 FLOPs ≈ 6 × 参数 × token。

口诀：文档拼一串，随机剪段，输入答案错一位；批乘长乘步数

B27 · 训练一步做哪几件事？该盯哪几条曲线？checkpoint 要存什么？

来源：第 5 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 一步：取 batch → 前向 → loss → 反向 → 裁剪 → 按当前 lr 更新 → 清梯度；每 N 步：验证、存档、记日志。
  • 盯四条线：train loss（抖，看趋势）、val loss（train 降 val 升 = 过拟合）、梯度范数（频繁超上限或暴涨 = 不稳）、学习率（是否按调度走）。
  • checkpoint：参数 + 优化器状态（m、v、动量）+ 步数，最好还有随机数状态。只存参数续训，动量和 Adam 的矩被清零，结果和不断训对不上。

口诀：存档三件：参数、优化器、步数，少一件就接不上

B28 · 老式编码器-解码器的瓶颈是什么？Bahdanau attention 的 e、α、c 怎么算？

来源：第 6 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 瓶颈：整句原文压进一个固定长度的向量，句子越长丢得越多。
  • Bahdanau：保留原文每个词的笔记 h_j（双向 RNN 输出）；写第 i 个词时 e_ij = a(s_{i−1}, h_j)，α_ij = softmax_j(e_ij)，c_i = Σ_j α_ij h_j，每一步的上下文都不同。
  • 加性打分 a = vᵀtanh(W s + U h)：一个小前馈网络。

口诀：每写一个词回头看，打分、softmax、加权求上下文

B29 · 加性打分和点积打分有什么区别？为什么 Transformer 选了点积？

来源：第 6 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 加性：vᵀtanh(Ws + Uh)，要学 W、U、v（Bahdanau 设定约 300 万参数），每一对 (s, h) 过一次网络。
  • 点积：sᵀh，无参数，只看方向是否一致；n 个 query × m 个 key 一次矩阵乘法 QKᵀ。
  • AIAYN §3.2.1：两者理论复杂度相近，点积实践中快得多、省内存；d 大时不缩放的点积会让 softmax 饱和，除以 √d_k 后就不输加性。Q、K 本身由可学矩阵得到，点积也有可学的“相关”标准（双线性形式）。

口诀：点积快又省，除以根号 d，就把加性比下去

B30 · Formal Algorithms 的 Algorithm 1–14 各是什么？怎么对上 a1 的题？

来源：第 7 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 1 token embedding、2 位置嵌入、3 单 query 注意力、4 整段注意力 + Mask、5 多头、6 LayerNorm、7 unembedding；8 / 9 / 10 是 encoder-decoder / encoder-only / decoder-only 的整体前向；11–13 训练，14–15 推理。
  • a1 走 Algorithm 10 这条线：embedding、rope（替换 2）、softmax + scaled_dot_product_attention（3、4）、multihead_self_attention（5）、rmsnorm（替换 6）、transformer_block / transformer_lm（10）、cross_entropy + adamw（13）、decoding（14）。
  • 读伪代码先看输入输出形状和参数表，再按行号对代码。

口诀：一到七是零件，十是 GPT，十三训练、十四生成

B31 · Algorithm 3 怎么算？Algorithm 10 每一行的形状怎么变？论文和 a1 的写法差在哪？

来源：第 7 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • Algorithm 3：q = W_q e，k_t = W_k e_t，v_t = W_v e_t，α = softmax(qᵀk_t/√d_attn)，输出 Σα_t v_t。
  • Algorithm 10：嵌入 → L 层（行 5–6 Pre-LN 注意力 X ← X + MHA(LN(X))；行 7–8 Pre-LN MLP，GELU）→ 行 10 最后 LN → 行 11 softmax(W_u X)。只有 MLP 中间维度变成 d_mlp，其余都是 d_e。
  • 论文一列一个 token（X ∈ ℝ^{d×ℓ}，左乘 WX）；a1 / PyTorch 一行一个 token（(B, ℓ, d)，右乘 XWᵀ），形状互为转置。

口诀：先 norm 再子层，结果加回 X；论文一列一 token，a1 一行一 token

B32 · 一次矩阵乘法多少 FLOPs？“训练 ≈ 6ND”的 6 是怎么来的？

来源：第 8 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • (m × k) @ (k × n) = 2mnk（每个输出 k 次乘、k 次加）；一个 token 过一个权重矩阵，每个参数 2 FLOPs。
  • 反向要算两样：∂L/∂x = (∂L/∂y)Wᵀ（传给上一层）和 ∂L/∂W = xᵀ(∂L/∂y)（给优化器），各一次同样大的矩阵乘法 → 4。
  • 前向 2 + 反向 4 = 每个参数每个 token 6；训练 FLOPs ≈ 6ND，推理每个 token ≈ 2N。

口诀：前二后四，训练六 N D

B33 · 一层的 FLOPs 花在哪？注意力什么时候不能忽略？

来源：第 8 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 一层一个 token 前向：QKV 6d²、输出投影 2d²、FFN 4df（f = 4d 时 16d²），合计 24d²（对应 12d² 个参数）；注意力 QKᵀ 2nd、AV 2nd，没有参数，6ND 数不到。
  • 比值 4nd / 24d² = n/(6d)：d = 4096、n = 2048 时 0.083（6ND 很准）；n = 32768 时 1.33（注意力比参数矩阵还多）。因果 mask 下平均只看一半。

口诀：比一比 n 和六倍宽：远小于就忽略，接近了就算上

B34 · BERT 的 MLM 怎么遮词？为什么不全换成 [MASK]？

来源：第 9 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 双向模型不能直接“看全句猜每个位置”：每个词能通过注意力看到自己，复制就能把 loss 降到 0。
  • MLM：每条序列随机选 15% 的位置；其中 80% 换 [MASK]、10% 换随机词、10% 不变；只在选中的位置算交叉熵猜原词。
  • 不全换 [MASK]：微调和使用时没有 [MASK]，全换会让预训练和使用对不上；留 10% 随机、10% 不变，迫使每个位置的表示都靠得住。
  • 输入：[CLS] 句首（输出当整句表示）、[SEP] 分隔；token + 句子 + 位置三种嵌入相加；NSP 后来被 RoBERTa 去掉。

口诀：完形填空十五分，八成遮罩、一成随机、一成不动；只在选中处算 loss

B35 · 为什么现在的大模型几乎都是 decoder-only？

来源：第 9 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 训练信号密：CLM 每个位置都在猜下一个（512 长 → 511 个信号），MLM 只有 15%（77 个）。
  • 天生会生成，提示、少样本自然成立；所有任务都能写成“接着往下写”，一个目标通吃。
  • 推理能用 KV cache：因果下前面的 K、V 算一次就能复用；双向模型每加一个 token 都要重算。
  • 双向模型留在检索嵌入、分类、MAE、DiT 等不需要逐个生成的地方。

口诀：每个位置都出信号、天生会生成、还能 KV cache

B36 · 什么是残差流？“写进不同子空间”是什么意思？

来源：第 10 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 每层都是 X ← X + 子层(X)，展开 x_L = x_0 + Σ 各头输出 + Σ 各 MLP 输出：一条只加不擦的主干（共享白板）。
  • 每个组件通过自己的 W_Q、W_K、W_V 读残差流，再把结果加回去；不同组件可以写进不同方向（子空间），后面的组件专门读某块（K-composition：后一个头的 W_K 读前一个头写的子空间）。

口诀：残差流是共享白板，每层只加不擦；写进不同子空间，后面的头各读各的

B37 · induction head 由哪两个头组成？各读什么、做什么？它和上下文学习有什么关系？

来源：第 10 章 · 加入 2026-11-25 · 复习记录：（必背，还没考）

答案
  • 第 1 层 previous token head：每个位置看前一个位置，把那个 token 写进残差流的另一块子空间（“我前面是谁”）。
  • 第 2 层 induction head：query = 当前 token，key = 每个位置的“前一个 token”，value = 那个位置的 token；找到“前面是我”的位置，把它复制出来：[A][B] … [A] → [B]。学的是算法，不是具体词对。
  • 必须两层；训练中它突然出现的时刻，loss 曲线有个鼓包、上下文学习能力同时跳升，去掉它能力大降。

口诀：第一头贴纸条“我前面是谁”，第二头拿着自己去比纸条；A B 再见 A，就猜 B

B38 · Annotated Transformer 的残差连接和 LayerNorm 和论文、PyTorch 有什么不同？

B40 · Post-LN 和 Pre-LN 各怎么写？为什么 Post-LN 离不开 warmup？

来源：第 12 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • Post-LN：z = Norm(x + f(x))，主干每层都被 norm；Pre-LN：z = x + f(Norm(x))，主干不过 norm，最后补一个 norm。
  • Xiong 等 Theorem 1：初始化时最后一层的梯度，Post-LN O(d√ln d)（与层数 L 无关），Pre-LN O(d√(ln d / L))（随 1/√L 变小）。玩具验证：Post-LN 6–48 层都约 250，Pre-LN × √L 约 350。
  • Post-LN 靠近输出的层梯度大，正常学习率一上来就走太远，必须先用小学习率 warmup；Pre-LN 梯度均匀，可以去掉或缩短 warmup。
  • Pre-LN 的代价：主干越加越大、最后要补 norm；变体（sandwich、OLMo 2 的 x + Norm(f(x))、DeepNorm）都是“norm 放子层两头、不打断主干”。

口诀：Post-LN 输出附近梯度大、和层数无关，不 warmup 就炸；Pre-LN 按根号 L 变小

B41 · RMSNorm 和 LayerNorm 差在哪？为什么更快？

来源：第 13 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • LayerNorm：γ(x − μ)/√(σ² + ε) + β；RMSNorm：g·x/RMS(x)，RMS = √(mean(x²) + ε)，不减均值、没有 β。RMS² = σ² + μ²，均值为 0 时两者一样。
  • 不变性：LayerNorm 对平移和缩放都不变；RMSNorm 只对缩放不变。论文认为缩放不变才是关键，效果相当，LLaMA、Qwen 等都用 RMSNorm。
  • 快在哪：norm 不到 1% 的 FLOPs，但它是逐元素操作，受显存带宽限制（FLOPs 不等于运行时间）；RMSNorm 少一步运算、少一份参数，读写就少。实现时先升到 float32 再算。

口诀：不减均值只除均方根；缩放不变才是关键；搬得多算得少，少一步就快

B42 · SwiGLU 的公式是什么？为什么 d_ff 取 8/3·d？

来源：第 14 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • SiLU(x) = x·σ(x)：平滑的 ReLU，负半轴略低于 0（最低约 −0.278）。
  • FFN_SwiGLU(x) = (SiLU(xW) ⊙ xV)W₂：一路当门、一路当内容，逐元素相乘；门接近 0 的维度把内容关掉，是一种乘法交互。论文只说“归功于神的恩典”。
  • 三个矩阵：3·d·d_ff = 8d² ⇒ d_ff = 8d/3，参数和计算量与 d_ff = 4d 的普通 FFN 一样；实际取整到 64（a1）或 256（LLaMA-7B 的 11008）的倍数。通常不带 bias。

口诀：一路门一路内容，逐元素一乘；三个矩阵乘三分之八

B43 · RoPE 想解决什么？二维和 d 维各怎么转？

来源：第 15 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • 目标（RoFormer 式 11）：⟨f_q(x_m, m), f_k(x_n, n)⟩ 只依赖内容和 m − n。

B44 · RoPE 实际怎么实现？配对方式有什么坑？为什么远处分数偏低？

来源：第 15 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • 不乘分块旋转矩阵，用式 (34)：R_m x = x ⊙ cos(mΘ) + rotate_half(x) ⊙ sin(mΘ)，cos、sin 预先算表。

B45 · ALiBi 怎么加位置？为什么能外推？NoPE 为什么不加位置也行？

来源：第 16 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • ALiBi：softmax(q_iKᵀ + m·[−(i−1), …, −1, 0])，按距离线性扣分；不改 q、k，不加在词向量上；m 不学，8 个头是 1/2 … 1/256（一般 2^{−8k/H}）。

B46 · RoPE 直接外推为什么会崩？PI 和 NTK-aware 各怎么改？

来源：第 17 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • 慢的平面（波长 > 训练长度）在训练里连一圈都没转完；读更长时转到没见过的角度（d = 128、训练 4096 → 32768：最慢平面 0.473 → 3.784 弧度）。快的平面所有角度早都见过。
  • PI：位置 m → m/s，所有平面都慢 s 倍；慢平面回到见过的角度，但快平面分辨率也掉了 s 倍。少量微调即可。
  • NTK-aware：底数 b′ = b·s^{d/(d−2)}，最快平面不变，最慢平面正好慢 s 倍，中间平滑过渡（s = 8 时 10000 → 82,685）。缺点是最佳底数难定。

口诀：只见过半圈的慢钟会转到没见过的角度；PI 全压，NTK 改底数

B47 · YaRN 做了哪两件事？

来源：第 17 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • NTK-by-parts：看每个平面在训练长度里转了几圈 r = L/λ。r > β（32）不动；r < α（1）完全插值 θ/s；中间按 γ = (r − α)/(β − α) 线性过渡：θ′ = (1 − γ)θ/s + γθ。快平面保住近处分辨率，慢平面回到见过的角度。

口诀：转满三十二圈不动，不到一圈全插值，中间线性过渡；再乘零点一 ln s 加一

B48 · 注意力 logit 为什么会越涨越大？QK-norm 怎么治？

来源：第 18 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • logit = q·k/√d，q、k 都和 W_Q、W_K 成正比；权重各变大 c 倍，logit 变大 c² 倍（例：×2 → 2.84 到 11.36）。
  • 后果：softmax 塌成 one-hot（熵坍缩，×8 时平均熵 0.024），饱和处梯度几乎为 0、被选中处又很大，训练发散。小模型用大学习率就能复现。
  • QK-norm：点积前把 q、k 各自 RMSNorm（可带可学缩放），|logit| ≤ √d，不随权重变；大幅降低学习率敏感度。Qwen3、OLMo 2 都用。

口诀：W 大 c 倍，logit 大 c 方，softmax 塌成独热；QK 先 norm 再点积，上界根号 d

B49 · 输出 logit 发散是什么？z-loss 怎么写？工业上怎么组合这些稳定性手段？

来源：第 18 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • softmax 对整体平移不敏感，log Z（Z = Σe^{y}）没有力量固定，训练后期会漂到很负，数值出问题。
  • z-loss = 10⁻⁴·(log Z)²，把 log Z 拉回 0，不改变概率（[30, 25, 20]、[0, −5, −10]、[−40, −45, −50] 交叉熵一样，z-loss 0.09、0、0.16）。权重衰减也能缓解。
  • OLMo 2：RMSNorm、子层输出的 norm（h = x + Norm(f(x))）、QK-norm、z-loss、RoPE θ = 5e5；再加 warmup、梯度裁剪、权重衰减。

口诀：softmax 不管平移，log Z 漂走；z-loss 万分之一乘 log Z 平方

B50 · 什么是巨大激活和 attention sink？滑窗推理为什么崩，StreamingLLM 怎么修？

来源：第 19 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • 巨大激活：少数固定维度（LLaMA2-7B 的 1415、2533）在句首、第一个句号等 token 上比其余大上万倍，和输入无关，像固定偏置；把注意力吸到这些 token 上。
  • attention sink：softmax 权重必须加到 1，没东西可看的头把权重停在句首（value ≈ 0，等于空操作）；句首对所有位置可见，最容易被学成 sink。例：句首拿 94%。
  • 滑窗推理丢掉句首，权重被迫摊给真实内容，输出乱掉（差 0.386）；StreamingLLM 永远保留开头 4 个 token 的 KV + 最近 W 个（差 0.015）。也可以预训练时放专门的 sink token，或 softmax 分母加 1。

口诀：票必须投完，投给句首弃权箱；滑窗踢掉句首就乱，留住开头四个就稳

B51 · 为什么换宽度要换学习率？μP 怎么做？

来源：第 20 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案
  • 标准初始化 W ~ N(0, 1/fan_in) 让前向和宽度无关；但 Adam 一步每个权重挪约 ±lr，方向和 x 对齐，Δy = Σ_j ΔW_ij x_j 是 n 个同号相加，∝ lr·n（宽 256 → 4096：0.21 → 3.28）。所以大模型的最优学习率往小处漂。
  • μP：隐藏层的 Adam 学习率 ∝ 1/宽度（再配套改输入、输出层和注意力缩放 1/d），各宽度下更新效果一样（都约 0.2）。
  • μTransfer：在小模型上调好超参，直接搬到大模型。

口诀：初始化管住前向，Adam 一步按宽度涨；隐藏层学习率除以宽度

B52 · DeepNorm 怎么写？α、β 怎么取？

来源：第 20 章 · 加入 2026-11-26 · 复习记录：（必背，还没考）

答案

来源：第 46 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 每一格单独做二分类："这对图文是不是一对"：\(\mathcal{L} = -\frac{1}{|B|}\sum_{i,j}\log\sigma\big(z_{ij}(t\,x_i\cdot y_j + b)\big)\)，\(\sigma(x) = 1/(1+e^{-x})\)。
  • \(z_{ij}\)：对角线 +1，其余 −1。不需要整行、整列的 softmax 分母，分数表可以分块算，不用收集所有卡的向量。
  • 反例格子（\(N^2 - N\)）远多于正例（N），一开始 loss 被反例主导；初始化 t = 10（t′ = log 10）、b = −10，让模型先倾向说"不配"，免得第一步大幅修正。
  • batch 小于 16k 时明显好于 softmax 版。

口诀：每格判一判，sigmoid 加偏置，负十先说不配

B10 · MAE 遮多少？encoder 和 decoder 各看什么？loss 在哪些块上算、目标是什么？

来源：第 47 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 随机、均匀地遮掉 75%（BERT 只遮 15%）：图片冗余大，遮少了从邻居一抄就补上。196 块只剩 49 块。
  • 不对称：encoder（大 ViT）只看露出的 25%，不放 mask token，注意力格子 1/16，训练快 3 倍以上；decoder（小，8 层、宽 512）看全部位置，被遮处放共享的可学习 mask token（加位置编码）。训完扔掉 decoder。
  • loss：只在被遮的块上算 MSE；目标是"每块各自减平均、除标准差"的归一化像素。
  • 例：[2, 4, 6, 8] → [−1.342, −0.447, 0.447, 1.342]，猜 [−1, −0.5, 0.5, 1] → MSE ≈ 0.060。

口诀：遮四分之三，专家只看露出的，助手补全；只算被遮的，每块先归一

B11 · DINO 的学生和老师是什么关系？loss 是什么？怎么防止坍缩？

来源：第 47 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 同一张图两个增强裁剪；学生、老师结构相同（ViT），各输出 K 维，带温度 softmax 成 \(P_s\)、\(P_t\)。
  • loss = 交叉熵 \(H(P_t, P_s) = -\sum_k P_t^{(k)}\log P_s^{(k)}\)，两个方向交叉取平均；只更新学生（老师 detach）。
  • 老师 = 学生参数的滑动平均：\(\theta_t \leftarrow \lambda\theta_t + (1-\lambda)\theta_s\)，λ 从 0.996 升到 1。
  • 防坍缩：centering（老师输出减中心 c，c 是老师输出的滑动平均，防止某一维独大）+ sharpening（老师用低温 \(\tau_t\) 0.04→0.07，防止变均匀），两者牵制。
  • DINOv2：精选的 LVD-142M、10 亿参数 ViT-g，特征冻住就能用。

口诀：学生贴老师，老师是学生的慢平均；减中心、低温度，不坍缩

B12 · DDPM 的前向过程一步怎么写？\(\bar\alpha_t\) 是什么？一步跳到第 t 步的公式是什么？

来源：第 48 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 一步（式 2）：\(x_t = \sqrt{1-\beta_t}\,x_{t-1} + \sqrt{\beta_t}\,\epsilon\)，\(\epsilon \sim \mathcal{N}(0, I)\)。先缩再加噪，方差保持 1。
  • \(\alpha_t = 1 - \beta_t\)，\(\bar\alpha_t = \alpha_1\alpha_2\cdots\alpha_t\)：前 t 步保留比例连乘。
  • 一步跳（式 4）：\(x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon\)（独立高斯相加还是高斯）。
  • 论文：T = 1000，β 从 \(10^{-4}\) 线性到 0.02；t = 500 时系数 0.280 / 0.960，t = 1000 时原图只剩 0.006。

口诀：每步先缩再加噪，阿尔法连乘一步跳

B13 · DDPM 训练时网络学什么？loss 是什么？生成的一步怎么算，为什么慢？

来源：第 48 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • Algorithm 1：取图 \(x_0\)，随机抽 t、抽噪声 ε，用式 4 造 \(x_t\)，网络 \(\epsilon_\theta(x_t, t)\) 猜 ε，\(L_{simple} = \mathbb{E}\lVert\epsilon - \epsilon_\theta\rVert^2\)（式 14）。猜噪声和猜原图等价，去掉权重效果最好。
  • Algorithm 2：从 \(x_T \sim \mathcal{N}(0, I)\) 出发，t = T…1：\(x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\big(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta\big) + \sigma_t z\)，\(\sigma_t^2 = \beta_t\)，最后一步不加 z。
  • 每步只减一小部分噪声，要走 1000 步 = 调 1000 次网络，所以慢。
  • 网络：U-Net + 16 × 16 层的自注意力；t 用 Transformer 的 sin / cos 编码告诉网络，所有步共用参数。

口诀：随机挑步撒噪声，网络专猜撒了啥；生成一千步，每步减一点、撒一点

B14 · Latent Diffusion 在哪里做扩散？下采样倍数 f 怎么选？文字条件怎么进去？

来源：第 49 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 先训自编码器：z = E(x)，\(\tilde x\) = D(z)，\(f = H/h\)；扩散全在 z 上做，生成后 D 解码。512 × 512 × 3 → 64 × 64 × 4（f = 8），小 48 倍。
  • f = 1、2 太慢；4–16 好；32 压太狠画质掉。自编码器管"看得出的细节"，扩散管"语义和构图"。
  • 条件 y 用 \(\tau_\theta\)（文生图里是 Transformer）编码成 M 个向量，U-Net 里加交叉注意力：\(Q = W_Q\varphi(z_t)\)，\(K = W_K\tau_\theta(y)\)，\(V = W_V\tau_\theta(y)\)；分数表 N × M（图像位置 × 文字 token）。
  • 目标：\(\lVert\epsilon - \epsilon_\theta(z_t, t, \tau_\theta(y))\rVert^2\)。

口诀：先画小稿再放大；画师边画看订单，图当 Q、文当 K V

B15 · Rectified Flow 的训练目标是什么？生成怎么做？路径为什么会弯、reflow 做什么？

来源：第 49 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • RF 约定 t = 0 噪声 \(X_0\)、t = 1 数据 \(X_1\)；直线 \(X_t = tX_1 + (1-t)X_0\)，目标速度 \(X_1 - X_0\)；\(\min_v\mathbb{E}\lVert(X_1 - X_0) - v(X_t, t)\rVert^2\)（式 1）。
  • 生成：解 ODE \(dZ_t = v(Z_t, t)dt\)，Euler：\(Z_{t+1/N} = Z_t + v/N\)。路径是直线时一步就到。
  • 随机配对的直线会交叉，交叉点的最优速度是各线的平均（\(v = \mathbb{E}[X_1 - X_0 \mid X_t]\)），ODE 路径不能交叉，于是改道变弯，少步数会走偏。
  • reflow：用训好的模型生成新配对 (\(Z_0\), \(Z_1\)) 再训一次，路径几乎变直，1 步 Euler 也能出好图。SD3 用它（SD3 写成 t = 0 是图）。

口诀：噪声连图走直线，网络只猜终点减起点；线交改道变弯，reflow 拉直

B16 · DiT 怎么把潜空间变成 token？条件 t、c 怎么进去？adaLN-Zero 的 α 为什么初始化成 0？

来源：第 50 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • patchify：潜空间 I × I × C（256² 图 → 32 × 32 × 4）按 p × p 切，\(T = (I/p)^2\)；p = 2 → 256 个 token。最后每个 token 解码回 p × p × 2C（噪声 + 方差）。
  • 四种条件方式里 adaLN-Zero 最好：\(\gamma, \beta, \alpha = \text{MLP}(e_t + e_c)\)，子层 \(x \leftarrow x + \alpha \odot f(\gamma \odot \text{LN}(x) + \beta)\)。每块 6 组：γ₁β₁α₁（注意力）、γ₂β₂α₂（MLP）；对所有 token 用同一组。
  • α 的 MLP 初始化输出 0 → 每块一开始是恒等函数（和残差同理），训练稳。
  • Gflops 越大 FID 越好；DiT-XL/2（28 层、d = 1152）FID 2.27。

口诀：潜图切块当 token；步数类别算出缩放平移；残差前加门，初始关上

B17 · SD3 的 MM-DiT 和 LDM 的交叉注意力有什么不同？SD3 怎么抽训练的 t？

来源：第 50 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 文字 token（CLIP-L、CLIP-G、T5 XXL）和图像 token（潜空间 2 × 2 切块）拼成一条序列做一次自注意力；两种 token 各用各的权重（\(W^Q, W^K, W^V\)、MLP），只在注意力那一步合在一起。
  • 交叉注意力只有"图看文"（N_img × N_txt）；联合注意力四块都有：图看图、图看文、文看图、文看文，文字 token 也随层更新。
  • t 和整句的 pooled 向量走 adaLN 调制。
  • 训练用 RF：\(z_t = (1-t)x_0 + t\epsilon\)（t = 0 是图），网络输出速度；t 用 logit-normal：u ~ 𝒩(0, 1)，t = sigmoid(u)，多练中间段。

口诀：图文拼成一条队，各用各的权重一起注意；t 用 logit 正态

B18 · 视觉语言模型的三段是什么？LLaVA、BLIP-2 的连接器各怎么做，各给 LLM 几个图片 token？

来源：第 51 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 图片编码器（冻住的 CLIP / SigLIP ViT）→ 连接器 → LLM；连接器输出长度必须等于 LLM 词向量长度，图片 token 排在文字前面一起进 LLM。
  • LLaVA：一个投影矩阵 \(H_v = W\cdot Z_v\)，CLIP ViT-L/14、224² → 256 个 token。两阶段：先只训 W（59.5 万对图文，对齐），再 W + LLM 一起微调（15.8 万条指令）。
  • BLIP-2：Q-Former（1.88 亿参数）里 32 个可学习的查询向量，用交叉注意力从 257 × 1024 的特征里取信息 → 32 × 768，再 FC 投影给冻住的 LLM。不管图多大都是 32 个 token。

口诀：作家只读自家词，先请翻译：一个矩阵投，或派三十二个记者采访

B19 · Qwen2-VL 的动态分辨率怎么算 token 数？M-RoPE 怎么给文字、图片、视频 token 编位置？

来源：第 51 章 · 加入 2026-11-18 · 复习记录：（必背，还没考）

答案
  • 不缩放：按原尺寸切 14 × 14 的块；ViT 去掉绝对位置编码，改用二维 RoPE；ViT 后用 MLP 把相邻 2 × 2 合成 1 个；首尾加 <|vision_start|>、<|vision_end|>。token 数 = (H/14)(W/14)/4 + 2，224² → 66。
  • M-RoPE：位置拆成（时间, 高, 宽）三个编号。文字三个相同（= 一维 RoPE）；图片时间相同、高宽按行列；视频每帧时间 + 1。
  • 换模态时，下一段从前面最大编号 + 1 开始。例：文字 0、1、2，2 × 2 的图是 (3,3,3)…(3,4,4)，后面的文字从 5 开始。

口诀：原图切块二乘二合一，首尾加标记；位置拆三号，换段最大加一
