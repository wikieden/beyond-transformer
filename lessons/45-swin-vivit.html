本章缩写：Swin = Shifted window（错开的 / 窗口）；W-MSA = Window-based Multi-head Self-Attention（窗口内 / 多头 / 自注意力）；SW-MSA = Shifted Window MSA（错开窗口的 MSA）；M：一个窗口的边长（几个小块）；Ω（读作"欧米伽"）：计算量；h、w：特征图的高和宽（几个小块）；C：每个小块向量的长度（Channels：通道）；ViViT = Video Vision Transformer（视频 / 视觉 / Transformer）；tubelet（小管子：一段时间里的同一块位置，切成一个立体小块）；\(n_t, n_h, n_w\)：时间、高、宽三个方向各切出几段（t = time，h = height，w = width）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：问题：全局注意力的代价是块数的平方（2026-11-18）

类比：全校大会 vs 分班开会。 ViT 每一层都开"全校大会"：每个小块要和所有小块各对一次话。人一多，"两两对话"的次数按人数平方涨。

Swin 原文（式 1、2，L203–L205）把两种做法的计算量写出来：

\[\Omega(\text{MSA}) = 4hwC^2 + 2(hw)^2C\]
\[\Omega(\text{W-MSA}) = 4hwC^2 + 2M^2hwC\]
符号 读法 意思
Ω 欧米伽 要做多少次乘加（不算 softmax）
h, w 特征图有 h 行、w 列小块，一共 hw 块
C 每个小块的向量长度
\(4hwC^2\) 每块乘 \(W^Q, W^K, W^V\) 和输出矩阵 \(W^O\)，四个 C × C 矩阵：和块数成正比
\(2(hw)^2C\) 全局：分数表 hw × hw，每格是长度 C 的点积；再乘 V 又一遍：和块数平方成正比
\(2M^2hwC\) 窗口：每块只和自己窗口里的 \(M^2\) 块算：和块数成正比

数字演示：Swin-T 第一阶段，224 × 224 的图按 4 × 4 切，h = w = 56（3136 块），C = 96，M = 7：

项 全局 MSA 窗口 W-MSA
投影 \(4hwC^2\) 1.16 亿 1.16 亿（一样）
注意力那一项 \(2 \times 3136^2 \times 96\) ≈ 18.9 亿 \(2 \times 49 \times 3136 \times 96\) ≈ 0.30 亿
合计 ≈ 20.0 亿 ≈ 1.45 亿（约 1/14）

注意力那一项差了 64 倍，正好是 hw / M² = 3136 / 49 = 64。图片边长再翻一倍（h = w = 112），全局那一项变 16 倍（302 亿），窗口那一项只变 4 倍（1.18 亿）。原文的说法是：全局是块数的平方，窗口是线性（L234–L237）。

一句话：全局注意力的代价是块数的平方；只在 M × M 的窗口里算，代价就变成和块数成正比。

第二步：窗口注意力：只在自己的窗口里开会（2026-11-18）

类比：分班开会。 把特征图切成不重叠的 M × M 窗口，每个窗口里的小块只和同窗口的小块做注意力（L245 起"Self-attention in non-overlapped windows"）。每个窗口内部就是普通的多头注意力（前作第 13 章），只是"一句话"变短了。

数字演示：一张 8 × 8 的特征图（64 块），M = 4，切成 2 × 2 = 4 个窗口，每个窗口 16 块：

做法 要算的分数格子
全局 64 × 64 = 4096
窗口 4 个窗口 × 16 × 16 = 1024

相对位置偏置（式 4，L320–L322）：Swin 不在输入上加位置编码，而是在每个窗口的分数表上加一张学出来的表 B：

\[\text{Attention}(Q, K, V) = \text{SoftMax}(QK^\top / \sqrt{d} + B)\,V\]

B 只看"两块之间差几行几列"，所以每个窗口共用同一张。这和前作第 17 章的 mask"在 softmax 前往分数上加东西"是同一个位置。

问题：窗口之间完全不说话。左上窗口的小块，永远不知道右边窗口里发生了什么。

一句话：把特征图切成 M × M 的窗口，只在窗口内做注意力，分数表从 64 × 64 变成 4 个 16 × 16；位置用分数上加的相对偏置 B。

第三步：窗口每层错开半格，信息就能跨窗口传（2026-11-18）

类比：换座位。 第 1 节课按 A、B、C、D 四组坐；第 2 节课每组往右下挪半组，新的一组里就混着原来几组的人。两节课下来，消息就跨组传开了。

原文（L229–L233）：第 ℓ 层按左上角对齐切窗口；第 ℓ + 1 层把窗口挪 \((\lfloor M/2 \rfloor, \lfloor M/2 \rfloor)\) 个小块（⌊ ⌋ 是向下取整）。两层成对出现（式 3，L240–L252）：

\[\hat z^\ell = \text{W-MSA}(\text{LN}(z^{\ell-1})) + z^{\ell-1},\quad z^\ell = \text{MLP}(\text{LN}(\hat z^\ell)) + \hat z^\ell\]
\[\hat z^{\ell+1} = \text{SW-MSA}(\text{LN}(z^\ell)) + z^\ell,\quad z^{\ell+1} = \text{MLP}(\text{LN}(\hat z^{\ell+1})) + \hat z^{\ell+1}\]

每一行都是第 44 章那种 Pre-LN 的"注意力 + 残差、MLP + 残差"，只是注意力换成了窗口版。

数字演示：还是 8 × 8，M = 4，错开 ⌊4/2⌋ = 2 格。行列从 0 数：

小块 第 ℓ 层（不错开）在哪个窗口 第 ℓ + 1 层（错开 2 格）在哪个窗口
(3, 3) 左上窗口（行 0–3，列 0–3） 中间窗口（行 2–5，列 2–5）
(4, 4) 右下窗口（行 4–7，列 4–7） 中间窗口（行 2–5，列 2–5）

第 ℓ 层这两块在不同窗口，互相看不见；第 ℓ + 1 层落进同一个窗口，可以直接对话。

cyclic shift（循环移位，L281–L312）：错开后边上会多出一些不满 M × M 的碎窗口（2 × 2 个窗口变成 3 × 3 个）。Swin 的做法是把整张图往左上"卷"一下，碎块拼成满的窗口，窗口个数不变；拼在一起但原来不相邻的块，用 mask 挡住不让它们互相看（前作第 17 章的 −∞）。

一句话：相邻两层一层正常切、一层错开半个窗口，原来分属两个窗口的块就能在下一层见面；碎窗口用循环移位 + mask 处理。

第四步：层层合并小块，得到金字塔（2026-11-18）

类比：地图缩放。 街道图看细节，城市图看全局。Swin 一开始用很小的块（4 × 4 像素），越往后越把相邻的块合并成大块，像 CNN 一样得到"由细到粗"的多层特征图。

  1. 起步：4 × 4 像素一块，每块 4 × 4 × 3 = 48 个数，线性投影成 C 维（L149–L157）。224 × 224 的图得到 56 × 56 块。
  2. patch merging（小块合并，L160–L172）：把每 2 × 2 个相邻块的向量首尾拼起来（4C 个数），再用线性层压成 2C。块数变成 1/4，向量变长一倍。
  3. 四个阶段：
阶段 特征图（块） 相对原图 向量长度（Swin-T） Swin 块数（Swin-T）
1 56 × 56 H/4 C = 96 2
2 28 × 28 H/8 192 2
3 14 × 14 H/16 384 6
4 7 × 7 H/32 768 2

Swin-T 的配置 C = 96、各阶段层数 {2, 2, 6, 2}、M = 7 见 L291、L298。最后一个阶段 7 × 7 正好是一个窗口。

为什么要金字塔：检测、分割要知道"东西在哪"，需要高分辨率的特征；ViT 从头到尾都是 14 × 14 一种尺寸。Swin 每一层都能当 CNN 主干的替代品接到检测头上，这是它在 COCO 检测、ADE20K 分割上大幅领先的原因（L84–L88）。

一句话：从 4 × 4 像素的小块起步，每个阶段把 2 × 2 个相邻块拼起来再压成 2C，得到 H/4 → H/32 的四层金字塔。

第五步：ViViT：视频切成"小管子"，先看空间再看时间（2026-11-18）

类比：切蛋糕。 视频是"一摞照片"：T 帧，每帧 H × W。ViT 是在一张照片上切方块；ViViT 是在整摞上切立方块，每块跨几帧（L176–L186）。

两种切法（§3.2，L196 起）：

切法 怎么切 token 个数
均匀抽帧（uniform frame sampling） 抽 \(n_t\) 帧，每帧按 ViT 切 \(n_t \cdot n_h \cdot n_w\)
tubelet 嵌入 切 t × h × w 的立方块（t 帧 × h × w 像素），相当于三维卷积 \(n_t = \lfloor T/t \rfloor\)，\(n_h = \lfloor H/h \rfloor\)，\(n_w = \lfloor W/w \rfloor\)

数字演示：32 帧、224 × 224 的视频，tubelet 16 × 16 × 2（ViViT 实验里用的尺寸，L411）：\(n_t\) = 32 / 2 = 16，\(n_h = n_w\) = 224 / 16 = 14，一共 16 × 196 = 3136 个 token。

两种模型怎么省（§3.3）：

模型 做法 注意力格子数
Model 1 时空一起看（L207 起） 3136 个 token 全部互相看 3136² ≈ 983 万
Model 2 先空间、后时间（factorised encoder，L283–L300） 每一帧的 196 块先在自己帧内看（空间 encoder），每帧汇总成一个向量；16 个帧向量再互相看（时间 encoder） 16 × 196² + 16² ≈ 61.5 万（约 1/16）

原文给的复杂度：Model 2 是 \(O((n_h n_w)^2 + n_t^2)\)，Model 1 是 \(O((n_t n_h n_w)^2)\)（L317–L318）。这和 Swin 的"只在窗口里看"是同一个思路：别让所有 token 两两对话，按结构分开看。

一句话：视频按 t × h × w 切成小管子；全部一起看是 token 数的平方，先在每帧内看、再在帧之间看能省一个数量级。

数学原理

  • 复杂度：全局 \(2(hw)^2C\)，窗口 \(2M^2hwC\)，比值 \(hw/M^2\)。
  • 错开半格：偏移 \(\lfloor M/2 \rfloor\)；相邻两层的窗口边界错开，任意两个相邻窗口在下一层都有交集。
  • patch merging：2 × 2 拼接 = 把空间换成通道（space-to-depth），再用线性层把 4C 压到 2C。
  • 分解注意力：\(O((n_t n_h n_w)^2)\) → \(O(n_t (n_h n_w)^2 + n_t^2)\)。

公式清单

公式 意思
\(\Omega(\text{MSA}) = 4hwC^2 + 2(hw)^2C\) 全局注意力的计算量（式 1）
\(\Omega(\text{W-MSA}) = 4hwC^2 + 2M^2hwC\) 窗口注意力的计算量（式 2）
\(\hat z^{\ell+1} = \text{SW-MSA}(\text{LN}(z^\ell)) + z^\ell\) 错开窗口的那一层（式 3）
\(\text{SoftMax}(QK^\top/\sqrt{d} + B)V\) 分数上加相对位置偏置（式 4）
\(n_t = \lfloor T/t \rfloor\)，\(n_h = \lfloor H/h \rfloor\)，\(n_w = \lfloor W/w \rfloor\) tubelet 切法

关键几行：

def window_id(r, c, M, shift=0):
    r, c = r - shift, c - shift              # 窗口往右下挪 shift，等于小块往左上挪
    return (r // M, c // M)                  # 同一个 (行号, 列号) 就是同一个窗口（负数也一样整除）

x = x.reshape(h // 2, 2, w // 2, 2, C)       # 每 2 × 2 个相邻块分成一组
merged = x.transpose(0, 2, 1, 3, 4).reshape(h // 2, w // 2, 4 * C)   # 一组 4 个向量首尾拼接

代码里才看得到的 2 件事：

  • 讲义说"窗口往右下挪"，代码里写成"小块坐标减去 shift"，两者等价；负坐标用 Python 的 // 向下取整，碎窗口自然分到边上的编号里，正好对应原文说的 3 × 3 个窗口。
  • patch merging 的拼接顺序（先行后列还是先列后行）各家实现不同，只要整个模型一致就行。
