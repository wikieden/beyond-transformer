本章回答：给图片打标签又贵又慢，网上却有几亿张"图 + 配文"。怎么用它们教模型看图？CLIP 的"一批里 N × N 的分数表，对角线是正确答案"是什么意思？为什么训完不用再训就能分类（zero-shot）？SigLIP 把 softmax 换成 sigmoid 又图什么？
讲解日期：2026-11-18 · 上一章：第 45 章 Swin 与 ViViT · 下一章：第 47 章 MAE 与 DINO
对应原文：CLIP transformer-deep-dive/materials/text/papers/clip-2103.00020.txt 数据 L143、§2.3 L228–L240、Figure 3 伪代码 L290–L316、温度 L266–L271 与 L325–L329、§3.1 zero-shot L364–L380、提示模板 L466–L471、ImageNet 76.2% L401；SigLIP siglip-2303.15343.txt §3.1 L125–L194、§3.2 L202–L231、初始化 L174–L186、Algorithm 1 L60–L80
本章缩写：CLIP = Contrastive Language–Image Pre-training（对比式 / 语言–图像 / 预训练）；SigLIP = Sigmoid loss for Language–Image Pre-training（sigmoid 损失的语言–图像预训练）；contrastive（对比：拿配对的和不配对的比）；embedding（嵌入向量，前作第 22 章）；L2 normalize（L2 归一化：把向量的长度缩放成 1，L2 = 欧几里得长度）；cos = cosine（余弦相似度）；τ（tau，读作"套"）：温度；t：温度的倒数（CLIP 伪代码里的放大倍数）；zero-shot（零样本：没见过这个任务的训练样本，直接上）；prompt（提示：套在类名外面的一句话）；σ = sigmoid（S 形函数，前作第 20 章）；b = bias（偏置）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：两个编码器，把图和文字放进同一个空间（2026-11-18）

类比：两种语言的同义词词典。 中文"狗"和英文"dog"是两个词，但在一本好的双语词典里它们挨在一起。CLIP 想做一本"图片 ↔ 文字"的词典：一张狗的照片和一句"一只狗"，要落在同一个地方。

数据：不用人标"这是狗"，直接用网上的图片和它的配文，一共 4 亿对（L143）。配文本身就是答案，和第 1 章"句子本身就是答案"一个道理。

结构（Figure 3，L290–L306）：

  1. 图片编码器（ViT，第 44 章；或 ResNet）把图片变成一个向量 \(I_f\)；
  2. 文字编码器（Transformer）把配文变成一个向量 \(T_f\)；
  3. 各乘一个投影矩阵 \(W_i\)、\(W_t\)，变成同样长度 \(d_e\)；
  4. L2 归一化：把每个向量的长度缩成 1。

长度都是 1 之后，点积就等于余弦相似度：两个向量方向越一致，点积越接近 1；垂直是 0。这就是前作第 2 章"点积量相似"的直接应用。

数字演示（编的，\(d_e\) = 2，已经归一化）：一批 3 对

图片向量 配文 文字向量
第 1 对 \(I_1\) = [1, 0]（狗的照片） "一只狗" \(T_1\) = [0.96, 0.28]
第 2 对 \(I_2\) = [0, 1]（猫的照片） "一只猫" \(T_2\) = [0.28, 0.96]
第 3 对 \(I_3\) = [0.6, 0.8]（鸟的照片） "一只鸟" \(T_3\) = [0.6, 0.8]

验证长度：\(0.96^2 + 0.28^2 = 0.9216 + 0.0784 = 1\) ✓。

一句话：图和文字各用一个编码器变成向量，投影到同一长度再归一化，点积就是"像不像"。

第二步：一批 N 对 → N × N 的分数表，对角线是正确答案（2026-11-18）

类比：联谊会配对。 3 个人各带一张照片，3 张纸条写着介绍。把每张照片和每张纸条都比一遍，得到 3 × 3 的表。真正一起来的那 3 对在对角线上，其余 \(N^2 - N\) = 6 格都是"配错的"（L234–L235）。

分数表：\(S = I_e T_e^\top\)（N × d 乘 d × N = N × N），第 i 行第 j 列 = 第 i 张图和第 j 段文字的余弦相似度：

\(T_1\) 狗 \(T_2\) 猫 \(T_3\) 鸟
\(I_1\) 狗图 0.96 0.28 0.6
\(I_2\) 猫图 0.28 0.96 0.8
\(I_3\) 鸟图 0.8 0.936 1.0

例：\(I_3 \cdot T_2 = 0.6 \times 0.28 + 0.8 \times 0.96 = 0.168 + 0.768 = 0.936\)。鸟图和"一只猫"也挺像，这一格待会儿会被罚。

温度：余弦只在 −1 到 1 之间，直接进 softmax 太"平"（前作第 7 章：分数差得小，比例就分不开）。所以乘一个放大倍数：

\[\text{logits} = I_e T_e^\top \cdot e^{t}\]

伪代码里写 np.exp(t)（L308），t 是学出来的；原文用温度 τ 表示（放大倍数 = 1/τ），初始 τ = 0.07（放大约 14.3 倍），放大倍数最多 100，防止训练不稳（L325–L328）。下面为了好算，放大 10 倍：

狗 猫 鸟
狗图 9.6 2.8 6.0
猫图 2.8 9.6 8.0
鸟图 8.0 9.36 10.0

一句话：一批 N 对两两打分得到 N × N 的表，正确配对在对角线上；乘上温度放大，让 softmax 分得开。

第三步：对称的交叉熵：按行猜文字，按列猜图片（2026-11-18）

两个方向各做一次"选择题"（伪代码 L311–L314）：

  • 按行：给一张图，在 N 段文字里选哪段是它的。每一行做 softmax，正确答案是对角线那一格，算交叉熵（第 1 章 −log p）。
  • 按列：给一段文字，在 N 张图里选。每一列做 softmax，同样看对角线。
  • 两个方向取平均，所以叫"对称的交叉熵"（symmetric cross entropy，L236）。
labels = np.arange(n)                              # 第 i 行的正确答案是第 i 列
loss_i = cross_entropy_loss(logits, labels, axis=0)
loss_t = cross_entropy_loss(logits, labels, axis=1)
loss   = (loss_i + loss_t)/2

数字演示：

按行 softmax（每行加起来是 1）：

狗 猫 鸟 对角线 p −log p
狗图 0.972 0.001 0.027 0.972 0.028
猫图 0.001 0.831 0.168 0.831 0.185
鸟图 0.081 0.317 0.601 0.601 0.508

按行平均 ≈ (0.028 + 0.185 + 0.508) / 3 ≈ 0.240。

按列 softmax（每列加起来是 1）的对角线：狗 0.831、猫 0.559、鸟 0.867，−log 分别是 0.185、0.581、0.143，平均 ≈ 0.303。

总 loss ≈ (0.240 + 0.303) / 2 ≈ 0.272。

训练会怎么推：要让对角线的概率变大，就得把对角线的分数往上推、其他格往下压。比如鸟图那一行，"一只猫"那格 9.36 太高，会被往下压，鸟图向量和"猫"的文字向量会被推开。一批里每张图都把其余 N − 1 段文字当"反面例子"，CLIP 用的 batch 是 32768（L329），一次就有三万多个反面例子。

一句话：每一行 softmax 是"图找文"，每一列 softmax 是"文找图"，都用对角线算交叉熵再取平均；一批越大，反面例子越多。

第四步：zero-shot：把类名写成一句话，比谁最像（2026-11-18）

类比：拿着词典认东西。 训练时从没教过"这 1000 类是什么"。要分类时，把每个类名套进一句话（prompt）：

"A photo of a {label}."（L470–L471）

用文字编码器把这 1000 句话各变成一个向量，再和图片向量算余弦，乘温度、softmax，挑最大的（§3.1，L364–L380）。原文说这等于一个"输入和权重都归一化、没有偏置、带温度"的线性分类器，只是权重是由文字编码器现场生成的（L376–L380）。

数字演示：一张新照片，向量 [0.96, 0.28]。三句话就用上面的 \(T_1, T_2, T_3\)：

类 余弦 × 10 softmax
狗 0.96 × 0.96 + 0.28 × 0.28 = 1.0 10.0 0.873
猫 0.96 × 0.28 + 0.28 × 0.96 = 0.538 5.38 0.009
鸟 0.96 × 0.6 + 0.28 × 0.8 = 0.8 8.0 0.118

判成"狗"。

为什么要套一句话：网上的配文大多是整句，很少只有一个词；套上"A photo of a …"更像训练时见过的文字（L466–L470）。CLIP 不用 ImageNet 的 128 万张标注图训练，zero-shot 在 ImageNet 上拿到 76.2%，和原版 ResNet-50 持平（L401）。

一句话：zero-shot 分类就是把每个类名套成一句话变成文字向量，和图片向量比余弦，最像的那个就是答案。

第五步：SigLIP：每一格单独判"配不配"（2026-11-18）

问题：CLIP 的每一行、每一列都要做 softmax，分母要把整行、整列加起来（L196–L199）。batch 分在很多张卡上时，得先把所有卡的向量收集到一起才能算分母，又慢又占内存。

SigLIP 的做法（§3.2，L202–L231）：不做选择题了，每一格单独做一道判断题："这张图和这段文字是不是一对？"用前作第 20 章的 sigmoid 把分数变成 0 到 1 的概率：

\[\sigma(x) = \frac{1}{1 + e^{-x}}\]
\[\mathcal{L} = -\frac{1}{|B|} \sum_{i=1}^{|B|} \sum_{j=1}^{|B|} \log \frac{1}{1 + e^{z_{ij}(-t\,x_i \cdot y_j + b)}}\]
符号 意思
\(\lvert B \rvert\) 一批几对
\(x_i \cdot y_j\) 第 i 张图和第 j 段文字的余弦（就是分数表那一格）
t 放大倍数（温度的倒数）
b 偏置，所有格子共用一个，学出来的
\(z_{ij}\) 标签：对角线（配对）是 +1，其余是 −1
每一项 \(-\log \sigma(z_{ij}(t\,x_i \cdot y_j + b))\)：配对的格子要分数高，不配对的要分数低

为什么要偏置 b：N 对里只有 N 格是正例，\(N^2 - N\) 格是反例，反例多得多。一开始如果什么都不偏，loss 会被大量反例主导，第一步就猛地改一大截。所以初始化 t = 10（t′ = log 10）、b = −10，让模型一开始就倾向于说"不配"（L174–L186）。

数字演示：同一张分数表，t = 10，b = −10，每格 logit = 10 × 余弦 − 10：

狗 猫 鸟
狗图 −0.4 −7.2 −4.0
猫图 −7.2 −0.4 −2.0
鸟图 −2.0 −0.64 0.0

每格的 loss = −log σ(z × logit)：

狗 猫 鸟
狗图 0.913（σ(−0.4) = 0.401） 0.001 0.018
猫图 0.001 0.913 0.127
鸟图 0.127 0.423 0.693

加起来除以 |B| = 3：≈ 1.07。对角线三格扣分最多：b = −10 让模型先说"都不配"，训练要做的是把配对的那几格往上推。

好处：每一格的 loss 只和这一格有关，不需要整行整列的分母。分数表可以一块一块地算（"chunked"，§3.3），batch 不大时（低于 16k）效果明显好于 softmax 版（L290–L293）。

一句话：SigLIP 把"N 选 1 的选择题"换成"每格一道判断题"，用 sigmoid、标签 ±1 和偏置 b = −10，不需要整行整列的 softmax 分母。

动画演示：一批图文的配对分数表

可交互版：animations/46-clip-siglip.html（需要用本地服务打开，见 animations/README.md"跑起来看"；滑块：放大倍数从 1 拖到 30，看按行 softmax 的对角线概率和 loss 怎么变）。

怎么看：

  1. 3 张图、3 段文字两两点积，得到 3 × 3 的表，对角线是正确配对（第二步）；
  2. 按行 softmax、按列 softmax，对角线取 −log，再平均（第三步）；
  3. 换成 SigLIP：每格各自 sigmoid，对角线标 +1、其余标 −1（第五步）；
  4. 滑块：放大倍数太小，每行的概率都差不多；放大后对角线变得突出。

口诀

图走图的编码器，文走文的编码器；投影归一化，点积就是余弦。
一批 N 对打 N 方格，对角线上是正解；温度放大分得开。
按行选文、按列选图，交叉熵两边各一半；一批越大反例越多。
类名套成一句话，最像的就是答案。
SigLIP 每格判一判，sigmoid 加偏置，不要整行分母。

数学原理

  • 归一化后点积 = 余弦：\(\cos\theta = \frac{a \cdot b}{\lVert a \rVert \lVert b \rVert}\)，长度都为 1 时就是 \(a \cdot b\)。
  • InfoNCE / 对称交叉熵：每行是一个 N 类分类，正确类在对角线；按列再做一遍。
  • 温度：logits 乘 1/τ；τ 越小，softmax 越尖。
  • sigmoid 二分类：\(-\log \sigma(z \cdot s)\)，z = ±1；和 softmax 不同，各格之间互不影响。

公式清单

公式 意思
\(S = I_e T_e^\top\) N × N 分数表（余弦）
\(\text{logits} = S \cdot e^{t}\) 乘放大倍数（1/τ）
\(\mathcal{L} = \frac{1}{2}(\text{CE}_{行} + \text{CE}_{列})\)，标签是对角线 CLIP 对称交叉熵
\(\hat y = \arg\max_k \cos(I, T_k)\)，\(T_k\) = "A photo of a {k}." zero-shot 分类
\(\mathcal{L} = -\frac{1}{\lvert B \rvert}\sum_{i,j} \log \sigma\big(z_{ij}(t\,x_i \cdot y_j + b)\big)\) SigLIP sigmoid 损失

关键几行：

logits = scale * (I @ T.T)                                  # N × N 分数表，再放大
row = -np.log(np.diag(softmax(logits, axis=1)))             # 每张图在 N 段文字里选
col = -np.log(np.diag(softmax(logits, axis=0)))             # 每段文字在 N 张图里选
loss = (row.mean() + col.mean()) / 2                        # 对称交叉熵

z = 2 * np.eye(n) - 1                                       # SigLIP 标签：对角线 +1，其余 −1
loss = -np.log(sigmoid(z * (t * S + b))).sum() / n          # 每格一道判断题，除以 |B|

代码里才看得到的 2 件事：

  • CLIP 伪代码里 axis=0 是"按列做 softmax"，也就是"文字找图"那一边；和讲义里的行 / 列一一对应时别看反。
  • SigLIP 的总和除的是 |B|（对数），不是 |B|² 个格子，所以数值看起来比 CLIP 大。

  • 把放大倍数从 10 改成 1，看按行 softmax 是不是变得几乎均匀，loss 变大。
  • 把 SigLIP 的 b 改成 0，看对角线和非对角线格子的 loss 各怎么变。
