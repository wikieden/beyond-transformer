动画

每章的关键原理配一个动画：GIF 嵌进讲义，同名 .html 是可交互版（▶ 播放、→ 单步、↺ 从头开始，有滑块的可以拖动参数）。anim.js、anim.css 和原版那本共用同一套。

跑起来看

可交互页面要用本地服务打开（直接双击打开时有的浏览器不让加载脚本）：

cd beyond-transformer/notes/animations && python3 -m http.server 8348

然后打开 http://localhost:8348/。录 GIF：node tools/anim-capture/capture.mjs <名字>.html <名字>.gif 1600。
