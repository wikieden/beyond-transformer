第 25 章 · 压缩、吸收，RoPE 单独拆出来

配套讲义：第 25 章 · MLA：把 K、V 压成一个小向量存，用时再展开；RoPE 为什么要单独拆出来。一个 token 的隐状态 h 被压成 512 维的 c 存进 cache；注意力时有两种写法：把每个历史 token 的 c 展开成 k，或者把 q 乘一次 W_UKᵀ 直接和 c 点积。

0

看点：① 第 1 步：h（5120 维）压成 c（512 维）存进 cache；② 展开写法：历史上每个 token 的 c 都要乘 W_UK 变成 k；吸收写法：只把 q 乘一次 W_UKᵀ；③ 最后一步：旁边多一条 64 维的 k^R 通道专门带 RoPE；右上角是每个 token 每层的 cache 元素数。
