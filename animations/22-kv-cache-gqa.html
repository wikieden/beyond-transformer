第 22 章 · 一个 token 一个 token 生成，cache 一格格变长

配套讲义：第 22 章 · KV cache 与 MQA / GQA：生成时为什么要存 K、V，怎么让它变小。上：已经生成的 token，最新的那个（亮）用它的 q 去看所有旧的 k。下：KV cache，每个 token 一列、每组 K/V 一行（8 个 Q 头）。

1

看点：① 每步只给新 token 算一次 K、V，追加成 cache 的新一列；② 右上角：从头算的投影次数按 1 + 2 + … + t 涨，带 cache 只按 t 涨；③ 切到 GQA、MQA：cache 的行数从 8 变成 2、1，字节数按比例缩小。
