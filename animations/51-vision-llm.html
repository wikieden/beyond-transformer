第 51 章 · 视觉接 LLM：图片小块 → 投影 → 插进文字序列

配套讲义：第 51 章 · 视觉接到大语言模型：图片变成"外语单词"，插进文字序列。三种连接器：LLaVA（一个投影矩阵）、BLIP-2（32 个查询向量）、Qwen2-VL（原尺寸 + 2 × 2 合并 + M-RoPE）。

448

看点：① 冻住的 ViT 出特征，连接器变成和词向量一样长的 token，排在文字前面一起进 LLM；② LLaVA：256 个小块 → 256 个 token；③ BLIP-2：32 个查询向量从 257 个特征里"采访"出 32 个 token；④ Qwen2-VL：不缩放，按原尺寸切，2 × 2 合并再加首尾标记；⑤ M-RoPE：每个 token 三个编号（时间, 高, 宽）。滑块：图越大，Qwen2-VL 的 token 越多。
